# GlobeLang

**GlobeLang** is a web-based language learning platform that connects students with native speakers around the world. It focuses on real-time conversations, enabling immersive practice in a global environment.

## Features

- Real-time chat interface for language exchange
- Language translation support to aid communication
- User registration and login system
- Organized user interface with clean and responsive design
- Simple front-end architecture using HTML, CSS, and JavaScript

## Project Structure

- `index.html`: Homepage of the application
- `chat/`: Chat system files
- `home/`: Home page after login
- `login/`: Login interface
- `registration/`: User registration page
- `translator.py`: Back-end translation logic (Python)
- `style.css`: Global styles for the application
